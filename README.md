# mlmultisim.github.io (retired — redirects to the new site)

This repository used to hold the Multi-scale Simulations Research Group's
website (a Hugo Blox / Wowchemy site), served at the awkward nested path
`https://multiscalesim.github.io/mlmultisim.github.io/`.

The group's site has since moved to
**[multiscalesim/multiscalesim.github.io](https://github.com/multiscalesim/multiscalesim.github.io)**,
served at the clean root URL **https://multiscalesim.github.io**.

This repo is kept around only so that the old URL doesn't 404 — it now
serves a minimal redirect page (`public/index.html` and `public/404.html`)
that forwards visitors to the new site. The old Hugo site content is still
available in this repo's git history if it's ever needed again.
